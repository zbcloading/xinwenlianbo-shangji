# 📡 新闻联播商机解读

> **新闻联播不是新闻，是加密的政策信号源。这条 Skill 帮你解码。**

一个 WorkBuddy / Claude Code / CodeBuddy 兼容的 Agent Skill，基于政策信号解码方法论，将新闻联播、外交辞令、政策文件中的措辞转化为结构化的商机解读报告。

## 两种分析模式

| 模式 | 输入 | 输出 | 适用场景 |
|------|------|------|---------|
| **单篇解读** | 一段新闻/外交辞令/政策文本 | 七节商机解读报告 | 快速理解单条新闻的商业含义 |
| **周期聚合** | 自动抓取日/周/月/季度新闻 | 八节周期商机报告 | 把握中长期政策趋势和投资方向 |

### 模式一：单篇解读

- **信号提取**：四层信号体系（宏观定调 → 行业落地 → 风险规避 → 信息结构）
- **措辞解码**：五套密码本精准匹配外交/政策/会议措辞
- **深度归因**：三问模型（为什么是现在？为什么是这个方向？普通人机会在哪？）
- **交叉验证**：多密码本联动判读，3+ 信号共振才下结论
- **量化评分**：五维打分（明确性 / 层级 / 可落地性 / 一致性 / 时间窗口）

### 模式二：周期聚合

- **自动抓取**：从央视网获取指定周期内所有新闻联播文字稿
- **逐日提取**：每天生成日摘要（头条方向 + 执行层动作 + 信号清单）
- **跨日聚合**：频次统计 / 趋势检测 / 优先级排序 / 主题聚类
- **对比分析**：前后周期对比，识别政策方向变化

## 抓取脚本

`scripts/fetch_xwlb.py` — 从 [央视网新闻联播](https://tv.cctv.com/lm/xwlb/) 抓取文字稿。

```bash
# 抓取最新一期
python scripts/fetch_xwlb.py --today --out ./news-data

# 抓取指定周期
python scripts/fetch_xwlb.py --week --out ./news-data
python scripts/fetch_xwlb.py --month --out ./news-data
python scripts/fetch_xwlb.py --quarter --out ./news-data

# 抓取指定日期
python scripts/fetch_xwlb.py --date 20260801 --out ./news-data

# 直接抓取详情页 URL 列表
python scripts/fetch_xwlb.py --urls "https://tv.cctv.com/...shtml,..." --date-str 20260801 --out ./news-data
```

输出目录结构：

```
news-data/
└── YYYY/
    └── MM/
        └── DD/
            ├── 001-标题.md
            ├── 002-标题.md
            └── ...
```

## 周期报告聚合维度

| 维度 | 计算方式 | 意义 |
|------|---------|------|
| **频次** | 主题出现天数 / 总天数 | 政策关注度的直接指标 |
| **优先级** | 频次×0.4 + 强度×0.3 + 层级×0.2 + 趋势×0.1 | 综合排序依据 |
| **趋势** | 前后半段频次对比（上升/平稳/下降/新出/消失） | 判断政策方向变化 |
| **聚类** | 五大类：科技/民生/外交/金融/安全 | 宏观结构洞察 |

## 边界

✅ **适合**：中长期产业趋势判断 / 外贸合作评估 / 规避政策打压行业 / 筛选政策安全标的  
❌ **不适合**：短线投机 / 精确择时 / 无行业知识的新手直接操作  
⚠️ **注意**：解读是概率性判断，单一信号不足以决策，必须交叉验证
